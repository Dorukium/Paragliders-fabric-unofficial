# Paraglider — unofficial Fabric 26.2 port

This is a modified version of **Paraglider 26.2.1** by Tictim, based on upstream tag
`26.2.1` (commit `21027aea65f13c45ca56e39ffd5a2dbc37148645`) from
<https://github.com/Tictim/Paraglider>.

The Fabric port replaces the NeoForge bootstrap, registries, events, networking,
attachments, capabilities, loot hooks, resource conditions and client integration
with Fabric equivalents. It is unofficial and is not supported or endorsed by the
upstream author; port-specific bugs must not be reported upstream.
